# Интерактивная лекция «Компоненты и props в React Native»

Готовый сайт для самостоятельного прохождения лекции студентами и одновременного просмотра прогресса преподавателем. Содержит **17 блоков** по материалам слайдов 2–32. В каждом блоке: теория → пример → проверочный вопрос → разбор ошибки → самостоятельное задание → результат (эталон).

## Запуск без npm install

Требуется **Node.js 18+ только на компьютере, который запускает сервер**. На устройствах студентов нужен только браузер.

1. Распакуйте ZIP целиком и откройте терминал в папке `react-native-interactive`.
2. Выполните `node server.js`.
3. В терминале появятся **код занятия** и **пароль преподавателя**.
4. На компьютере преподавателя откройте `http://localhost:3000/teacher.html` и введите пароль.
5. Студенты должны открыть сайт на своих устройствах, указать имя, группу и код занятия.

### Как дать студентам адрес

Для работы **с нескольких компьютеров** сервер должен быть доступен по локальной сети либо развёрнут на хостинге. Если компьютер преподавателя и устройства студентов в одной Wi-Fi/LAN сети, узнайте локальный IPv4-адрес компьютера преподавателя (например `192.168.1.25`) и попросите студентов открыть `http://192.168.1.25:3000`. Укажите порт 3000 и разрешите соединение в брандмауэре, если требуется.

**Важное ограничение:** если устройства находятся в разных сетях, адрес `localhost` и локальный IP для студентов работать не будут. Нужен размещённый в интернете сервер, защищённый HTTPS, либо организованный администратором сетевой доступ. Этот архив сам по себе не создаёт публичный адрес и не является облачным сервисом.

### Постоянные код занятия и пароль

По умолчанию код занятия и пароль генерируются при каждом запуске. Для одинаковых значений между запусками можно задать переменные среды перед запуском:

- PowerShell: `$env:ROOM='RN2026'; $env:TEACHER_KEY='сильный_пароль'; node server.js`
- macOS/Linux: `ROOM=RN2026 TEACHER_KEY='сильный_пароль' node server.js`

Рекомендуется использовать сложный пароль для панели преподавателя. Не показывайте его студентам.

## Прогресс и сохранение

- Студент сохраняет персональный токен в браузере (localStorage), поэтому в том же браузере можно продолжить прохождение после обновления страницы. При очистке данных браузера потребуется новый вход.
- Прогресс всех студентов записывается на сервере в `data/progress.json`; файл сохраняется после каждого обновления.
- Преподаватель видит ФИО, группу, полностью изученные блоки, завершённые этапы, число ошибочных попыток, общее число попыток, факт завершения и последнюю активность. Данные обновляются автоматически каждые 3 секунды.
- Доступны фильтр по группе, поиск и экспорт в CSV.
- Неверный ответ на тест и неуспешная автоматическая проверка кода увеличивают счётчик ошибок.
- **Проверка самостоятельного кода упрощённая:** поиск ключевых фрагментов в тексте. Это не компиляция и не выполнение React Native. Возможны ложные срабатывания/отклонения. Преподавателю рекомендуется проверять содержательно сложные решения отдельно.
- Возможность пропускать уже начатые блоки в навигации не даёт автоматического зачёта. Блок считается изученным только после прохождения 6 этапов и правильного ответа на вопрос и задание.

## Ограничения и конфиденциальность

Это учебный локальный сервер, а не защищённая промышленная платформа: отсутствуют централизованные учётные записи, HTTPS, резервное копирование, защита от намеренной подмены клиентских результатов и администраторское управление курсами. Для хранения реальных персональных данных на доступном в интернете сервере нужны дополнительные меры защиты, безопасная аутентификация, HTTPS, политика хранения и требования вашего учебного заведения.

Студенты могут заново войти под тем же ФИО и создать дублирующую запись. Для обычного занятия лучше попросить каждого открыть сайт один раз и продолжать в том же браузере.

## Содержимое

- `server.js` — сервер Node.js на стандартных модулях, без npm-пакетов.
- `public/index.html` и `public/student.js` — самостоятельное прохождение.
- `public/teacher.html` и `public/teacher.js` — мониторинг преподавателя.
- `public/content.js` — теория, примеры, вопросы, ошибки, задания и эталоны, которые можно редактировать.
- `public/styles.css` — внешний вид.
- `data/progress.json` — создаётся при первом сохранении.
